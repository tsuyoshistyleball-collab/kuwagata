# クワガタ フライング！ 🪲

4歳のお子さんでも簡単に遊べる、クワガタの横スクロールアクションゲームです。
スマートフォンでのプレイを想定して作られています。

## あそびかた

- クワガタは画面の左側を飛んでいて、景色が右から左へ流れていきます
- **画面をタッチ（長押し）している間は上にとび、指をはなすと下にさがります**
- 木の枝やキノコにぶつからないように避けながら、ゴールの旗を目指しましょう
- 途中の「昆虫ゼリー」を取るとカウントが増えます
- ハートは5個。ぶつかると1個減りますが、しばらく無敵になるので大丈夫
- ゴールすると紙吹雪でお祝い！🎉

## 4歳児向けのやさしい設計

- 操作はタッチのみ（ボタンなし・文字を読まなくても遊べる）
- 障害物のすき間は広め、当たり判定は見た目よりゆるめ
- 地面や画面の上にぶつかってもミスにならない
- 失敗しても「あちゃー！でもだいじょうぶ！」とすぐやり直せる

## スマートフォンで遊ぶ方法

1. このリポジトリの **Settings → Pages** で「Deploy from a branch」を選び、ブランチを設定して GitHub Pages を有効にする
2. 公開されたURL（`https://<ユーザー名>.github.io/kuwagata/`）をスマホのブラウザで開く
3. ホーム画面に追加すると、アプリのように全画面で遊べます
   - iPhone: Safari の共有ボタン →「ホーム画面に追加」
   - Android: Chrome のメニュー →「ホーム画面に追加」

※ PCの場合はブラウザで `index.html` を開くだけでも遊べます（スペースキーでも操作可能）。

## 技術構成

- 単一の `index.html` のみ（HTML + Canvas + JavaScript、外部ライブラリなし）
- サーバー不要・オフラインでも動作
- 画面サイズに自動対応（縦持ち・横持ちどちらでもOK）
- 効果音は Web Audio API で生成
